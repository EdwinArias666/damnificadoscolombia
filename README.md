# Ayudas Terremoto Colombia 2026

Aplicación web offline-first para damnificados del terremoto de Colombia (10 de agosto de 2026, Mw 7.4).

## Características

- **100% offline**: Funciona sin conexión a internet después de la primera carga
- **Sin dependencias**: HTML, CSS y JavaScript puro (ultra-liviano)
- **Información oficial**: Solo fuentes verificadas (UNGRD, Cruz Roja, Ministerio de Vivienda)
- **No cobra dinero**: La app NO recauda fondos ni solicita pagos
- **PWA instalable**: Se puede instalar como aplicación en el celular

## Funcionalidades

- Selector de departamento y municipio
- Formulario de tipo de afectación
- Guía personalizada de ayudas según ubicación
- Pasos del registro RUD (Registro Único de Damnificados)
- Números de emergencia
- Advertencias contra estafas

## Información incluida

- 15 departamentos afectados
- 426+ municipios
- 6 tipos de ayudas gubernamentales
- 4 pasos del registro RUD
- Contactos de emergencia
- Fuentes oficiales verificadas

## Fuentes oficiales

- UNGRD: portal.gestiondelriesgo.gov.co
- RUD: rud.gestiondelriesgo.gov.co
- Ministerio de Vivienda: minvivienda.gov.co
- Cruz Roja Colombiana
- Defensa Civil Colombia

## Uso

1. Abre `index.html` en tu navegador
2. Selecciona tu departamento y municipio
3. Indica el tipo de afectación
4. Recibe tu guía personalizada de ayudas

## Nota importante

Esta aplicación NO es una entidad gubernamental. NO recauda fondos, NO cobra trámites y NO solicita dinero. Toda la información proviene de fuentes oficiales verificadas.

Si alguien se hace pasar por esta aplicación para solicitar dinero, repórtalo a la Policía (123) o la Fiscalía (122).
